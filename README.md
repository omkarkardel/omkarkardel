## 🚀 About Me

I'm a **Full Stack Developer** who builds scalable **MERN Stack** applications end-to-end — and then ships, containerizes, and automates them like a **DevOps engineer**.

- 💻 Building applications with **React.js, Node.js, Express.js & MongoDB**
- 🔐 Designing secure **REST APIs, authentication & authorization systems**
- 🐳 Containerizing apps with **Docker** and orchestrating with **Kubernetes**
- ⚙️ Automating builds & deployments with **CI/CD** (GitHub Actions, Jenkins)
- ☁️ Provisioning infrastructure on **AWS** using **Terraform** (IaC)
- 📊 Exploring monitoring & observability (Prometheus, Grafana)
- 🧠 Sharpening **DSA & problem-solving** skills daily
- 🌱 Currently focused on bridging **development and operations** into one smooth workflow
